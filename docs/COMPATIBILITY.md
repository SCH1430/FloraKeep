# Запуск и совместимость Flora Keep

## Переносимый HTML

Откройте корневой `index.html` в браузере. Изображения, музыка и игровые функции входят в файл. Перед переносом игры в другую папку или браузер скачайте JSON в разделе «Сохранения». Откройте новый файл, восстановите сад и проверьте число растений, заметки и творческие работы.

Если после перехода с `Flora-Keep-2.5.0.html` открылся пустой сад, браузер мог привязать прежнее хранилище к имени файла. Откройте старый файл в прежней папке и в том же профиле браузера. Если файла уже нет, временно положите рядом с `index.html` его копию под прежним именем по точному старому пути. Скачайте JSON через «Сохранения», затем откройте `index.html` и восстановите копию. Для нескольких садов в окне «Мои отдельные сады» доступен экспорт всех профилей. Этот способ требует, чтобы браузер по-прежнему хранил исходные данные.

## Устанавливаемый сайт

Выполните `node scripts/release.mjs`, затем `node scripts/serve.mjs`. Откройте `http://127.0.0.1:4173/`. Пробный канал запускается командой `node scripts/serve.mjs --preview` на `http://127.0.0.1:4174/`. Разные порты дают этим каналам отдельные браузерные хранилища.

Для публикации разместите содержимое `dist/` на статическом HTTPS-хостинге. Манифест, `sw.js`, `index.html` и ресурсы с хешами в имени должны находиться на одном уровне. В браузере проверьте, появилась ли установка в меню, а после первого успешного открытия — запуск с отключённой сетью. Обновление предлагает сохранить работу перед переключением на новую версию.

Страница `download.html` содержит варианты запуска и ссылку на переносимый выпуск. В `SHA256SUMS.txt` указаны контрольные суммы файлов веб-выпуска. Строка `portable.html` относится к однофайловому выпуску, который скачивается под именем `index.html`.

## Обмен версиями общего сада

При первом обмене выберите полный зашифрованный файл. После изменения сада можно скачать только обновлённые растения, удаления, комментарии и записи журнала. Файл изменений открывается поверх полной копии того же сада в Flora Keep 2.5.0. Перед объединением можно сравнить версии и вручную выбрать, какую оставить.

Выставочная копия, афиша и каталог команд скачиваются как HTML для просмотра и печати. Для отдельной выставочной копии можно выбрать растения и скрыть подписи. Полные файлы команд открывайте в инструменте каталога, чтобы объединить работы по разделам и сохранить авторство.

## Матрица ручной проверки

Проведите сценарий отдельно в Chromium, Firefox и Safari, там, где режим доступен. Записывайте версию браузера, платформу, тип запуска и результат каждого шага.

| Что проверить | Контрольное действие |
| --- | --- |
| Локальный файл | Открыть HTML из папки, посадить росток, перезагрузить вкладку, проверить сохранение. |
| Перенос | Экспортировать сад с именем растения на кириллице. Открыть копию HTML в другой папке и восстановить JSON. |
| Мобильный интерфейс | Проверить экраны шириной 320, 768 и 1440 CSS-пикселей в светлой и ночной теме. Сделать скриншоты каталога, карточки ухода и редактора. |
| Клавиатура | Открыть дополнительные фильтры, оставить фокус на раскрывающем элементе и дождаться обновления. Проверить фокус при закрытии диалогов. |
| Экспорт медиа | Открыть скачанные PNG, GIF и HTML. Сверить размеры, кадры и кириллицу с предпросмотром. |
| Установка и запуск офлайн | Открыть HTTPS или локальный сайт, дождаться установки службы кэша, отключить сеть и перезапустить. |
| Обновление с черновиком | Открыть установленный сайт со старой сборкой, изменить сцену, подготовить новую сборку, обновиться и снова открыть черновик. |
| Сбой хранилища | Запретить запись или заполнить тестовое хранилище. Проверить предупреждение и аварийное скачивание. |
| Подоконник | На телефоне шириной 360 px выбрать сухое растение, полить, проверить влажность и перезагрузить сад. Проверить первую посадку и выбор растения с другой полки. |
| Гербарий | Открыть вид из указателя отпечатков, выбрать экземпляр и перейти к уходу. Повторить с текстом 200%. |
| Фотохроника | Открыть историю экземпляра с несколькими записями, сменить дату касанием и с клавиатуры, сверить дату и влажность. Проверить единственное наблюдение и длительный промежуток. |
| Сниженное движение | Включить уменьшение движения, полить растение и открыть показ цветения. Проверить статичные состояния и управление клавиатурой. |
| Иллюстрированные экспорты | Экспортировать полосу четырёх наблюдений, контактный лист, ответный диптих, каталог и этикетки. Проверить кириллицу, направляющие и поля в PNG или на печати. |

`node --test` проверяет игровую логику, форматы резервных копий и поведение веб-оболочки на тестовых адаптерах. Таблица выше предназначена для прогонов в браузерах и на устройствах.

В выпуске 2.6.0 в Edge 158 были проверены размеры 320 × 800, 360 × 800 и 1280 × 900 CSS-пикселей. Во всех трёх прошли выбор и полив растения, перезагрузка сохранения, переход между полками, выбор экземпляра в гербарии и навигация по фотохронике с клавиатуры. При ширине 360 px в тестовом саду из четырёх растений нижний край кнопки «Полить» находился на высоте 511 px от начала экрана. На ширине 320 px также проверены сад и гербарий с текстом 200%. В автономном HTML после отключения сети прошли первая посадка и полив. Для этого прогона использовались изолированные профили браузера и эмуляция размеров экрана.
