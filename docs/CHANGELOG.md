# Выпуски Flora Keep

## 2.6.0

- Корневой `index.html` открывает автономную игру. Веб-сборка получает отдельные кэшируемые иллюстрации подоконника для широких и узких экранов.
- В саду можно выбрать горшок и полить растение на подоконнике. Гербарий сопоставляет ботанический отпечаток с цветным портретом. Фотохроника показывает состояние растения по датированным наблюдениям.

## 2.5.0

- Визуально обновлены сад, гербарий, атлас, погодные сцены, растения, мастерские, мини-игры и выставочные материалы. Реализация каждого пункта описана в [визуальном списке](DESIGN.md).
- Рисунки, визуализации ухода и журнальные графики вынесены в самостоятельные модули. Настройки света и вида за окном показываются в предпросмотре до сохранения.
- Фотостудия получила паспарту, макет на весь кадр, направляющие, альбомную полосу и контактный лист. Подарок и выставка получили отдельные печатные макеты.

- При расчёте прогноза обрабатывается только выбранное растение. В тесте Node.js серия из 100 прогнозов заняла 0,16 мс вместо 7,5 мс.
- Обычные фоновые пересчёты объединяются в запись раз в пять минут. Действия, новые наблюдения и записи журнала сохраняются сразу.
- Поиск скрывает существующие карточки, а обновление сада сохраняет неизменённые блоки и их фокус. Иллюстрации переиспользуют индекс оформления, включая авторские горшки.
- Кодирование набора из 12 непрозрачных кадров GIF заняло 30 мс вместо 212 мс в Node.js. Результат совпал побайтово. Браузерный экспорт переиспользует холст и передаёт буферы кадров рабочему потоку.
- Веб-оболочка загружает версии JavaScript, CSS и звука отдельными файлами. Локальный сервер кеширует файлы по их хешам и сжимает JavaScript и CSS через Brotli. Служба офлайн-доступа сохраняет все эти ресурсы.

- Исходники игры, мастерских и оформления можно собирать в переносимый HTML командой `node scripts/build.mjs`.
- После `node scripts/release.mjs` в папке `dist/` доступны веб-версия, страница загрузки, переносимая копия и контрольные суммы.
- Для локальной проверки есть обычный и пробный каналы на разных портах.
- Добавлены проверки игрового времени, импорта прежних форматов, экспорта медиа и офлайн-оболочки.
- Общий сад показывает разницу перед объединением, хранит журнал, комментарии и заметки, экспортирует выставочные материалы и каталог команд.
- Добавлены маршруты первого запуска, учебная теплица, уход в зависимости от места и грунта, паспорта и родословные растений.
- Флорариум поддерживает историю действий, слои и перенос проектов. Театр поддерживает программу из сцен, реплики, траектории, кадрирование и сохранённые мелодии.
- Восстановление сохраняет предыдущий сад при отказе записи. Есть пробный импорт, архив профилей и состав резервной копии на выбор.
- Фильтры сада реагируют на рост и влажность. При автообновлении сохраняются существующие кнопки, а каталог сохраняет раскрытые фильтры.
- В переносимой сборке частота дискретизации фоновой музыки уполовинена. Исходная дорожка сохранена в исходниках.
- Полные зашифрованные файлы общего сада используют прежний формат. Файлы только с изменениями требуют версию 2.5.0 и предварительно открытый полный файл того же сада.
