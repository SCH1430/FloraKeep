# Показ Flora Keep

## Подготовка

- Откройте `scene.html` и `postcard.svg` из этой папки. Проверьте, что они отображаются на устройстве, с которого будете вести показ.
- Для интерактивной части откройте Flora Keep и создайте отдельный профиль с именем «Выставка». Загрузите в него `garden.json` через «Сохранения». Образец содержит демонстрационные растения, записи и сцену.
- Для повторения показа можно снова восстановить этот же JSON в выставочном профиле.

## Сценарий на пять минут

1. Покажите сад и отфильтруйте экземпляры, которым нужна вода.
2. Откройте ромашку, сравните её с лавандой и найдите один факт в ботаническом кабинете.
3. Откройте готовую сцену и покажите, как композиция превращается в переносимый HTML.
4. Дайте зрителю выбрать один самостоятельный шаг. Подойдёт полив, изменение горшка или добавление объекта во флорариум.
5. Предложите показать результат через открытку или продолжить работу из черновика.
