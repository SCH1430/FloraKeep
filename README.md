# Flora Keep 2.6.0

Flora Keep — локальная игра об уходе за растениями, ботанике и творческих работах. Проект вырос из эскизов учениц 8-И класса школы № 1430.

Откройте [index.html](index.html) в браузере. Весь сад, иллюстрации и звук входят в этот файл. Если браузер открыл пустой сад после смены имени файла, восстановите JSON через «Сохранения». [Как найти сад из прежней версии](docs/COMPATIBILITY.md#переносимый-html)

## Сборка

Требуется Node.js 22 или новее. Пакеты устанавливать не нужно.

```text
node scripts/build.mjs
node --test
node scripts/benchmark.mjs
node scripts/release.mjs
node scripts/serve.mjs
```

`build.mjs` собирает переносимый HTML из `src/`. `release.mjs` дополнительно собирает сайт, офлайн-оболочку, выставочные материалы и контрольные суммы в `dist/`. Локальный сайт открывается по адресу `http://127.0.0.1:4173/`. Ключ `--preview` запускает пробный канал на отдельном порту.

## Исходники

- `src/game.js` содержит правила времени, ухода, экономики и роста.
- `src/app.js` отвечает за корневой интерфейс, управление профилями и запись сада.
- `src/windowsill.js` формирует интерактивную полку, `src/cyanotype.js` — разворот гербария, а `src/chronicle.js` — фотохронику экземпляра.
- `src/backup.js`, `src/save-format.js` и `src/exchange.js` реализуют копии, миграции и обмен.
- `src/features.js` соединяет мастерские, каталог, ботанику и инструменты сада.
- Мастерские находятся в отдельных модулях. Стили собираются из `src/styles/` в порядке имён файлов.
- `test/` содержит проверки игровых правил, форматов, сборки и отдельных сценариев интерфейса на адаптерах.
